# GYMS.LIFE typography

Self-hosted, complete variable fonts from Google Fonts. Both are licensed under
the SIL Open Font License 1.1; the accompanying license files must travel with them.
Original binaries are retained without modification or subsetting, including
extended Latin glyphs for Lithuanian. No remote font stylesheet is required.

| File                         | Source                                                 | Original Git blob                          |
| ---------------------------- | ------------------------------------------------------ | ------------------------------------------ |
| `manrope-variable.ttf`       | `google/fonts/ofl/manrope/Manrope[wght].ttf`           | `75274da58537d6123b14f2cd0c355ad4681fc2b3` |
| `space-grotesk-variable.ttf` | `google/fonts/ofl/spacegrotesk/SpaceGrotesk[wght].ttf` | `a1b2e6c26093066510a31147e7aec9abdc8d6c5e` |

Manrope carries interface copy. Space Grotesk carries display titles, brand and
important metrics. Use tabular numerals for measurements; keep status colors
semantic and preserve unknown / unavailable states.
