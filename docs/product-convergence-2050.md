# GYMS.LIFE Product Convergence 2050

## Product rule
GYMS.LIFE is one continuously operating human-performance intelligence system, not a collection of fitness apps.

The user should learn four places only:
- **Today** — the single governing action now.
- **Twin** — the athlete state across past, present and bounded future.
- **Lab** — hypotheses, experiments, calibration and model learning.
- **Coach** — the conversational interface to the same system.

Everything else is a contextual capability invoked by those worlds. A capability can remain technically powerful without owning navigation.

## What is already over-specified
Today currently contained multiple competing intelligence summaries. `TodayDecision` should own decision authority. Narrative briefs, raw physiology, recovery projections and evidence panels are supporting layers, not peers.

Twin previously split muscle state into a separate top-level tab despite the body already being interactive. Muscle tables and trend tools belong inside Body as deeper inspection.

Future Me and Journal behaved like separate products. They are temporal views of the same Twin and should feel continuous with the current athlete model.
## What creates the 2050 effect
1. **One governing answer, not a dashboard of opinions.** Today chooses one action and exposes evidence on demand.
2. **A living Twin, not charts.** Current body state, measured systems, bounded future trajectories and auditable memory are one temporal model.
3. **Ambient intelligence.** Night Lab and background engines work without requiring the user to open a screen; the UI reports what changed rather than advertising jobs.
4. **Provenance everywhere.** Measured, reported, calculated, inferred, predicted and simulated states must remain visibly distinct.
5. **Progressive disclosure.** Expert detail exists, but never competes with the primary decision.
6. **Contextual tools.** Camera, voice, meal vision, AR, supplements and planning appear at the moment they are useful.
7. **Self-evaluation.** Lab must show when predictions were wrong, evidence weakened, or a hypothesis was contradicted.
